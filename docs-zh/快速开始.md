## 一、安装

### 1.1 系统要求

- **操作系统**: Linux / macOS / Windows (WSL2)
- **运行时**: Bun 1.3.10+ (自动安装)
- **Node.js**: 22+ (可选，兼容模式)

### 1.2 从源码安装

```bash
# 克隆仓库
git clone https://github.com/anomalyco/opencode.git
cd opencode

# 安装依赖
bun install

# 构建（可选，开发模式不需要）
bun run build
```

### 1.3 验证安装

```bash
# 运行帮助
bun run dev --help

# 检查版本
bun run dev --version
```

## 二、配置

### 2.1 环境变量

创建 `.env` 文件或设置系统环境变量：

```bash
# 服务器密码（推荐设置）
export OPENCODE_SERVER_PASSWORD=your-secure-password

# 服务器用户名（可选，默认 opencode）
export OPENCODE_SERVER_USERNAME=your-username

# AI 提供商 API Key
export ANTHROPIC_API_KEY=sk-ant-xxx
export OPENAI_API_KEY=sk-xxx
export GOOGLE_API_KEY=xxx
```

### 2.2 配置文件

配置文件位置：`~/.opencode/config/`

**示例配置** (`config.json`):

```json
{
  "server": {
    "port": 4096,
    "hostname": "0.0.0.0",
    "mdns": false
  },
  "provider": {
    "anthropic": {
      "apiKey": "sk-ant-xxx"
    }
  },
  "agent": {
    "build": {
      "permission": [
        { "permission": "bash", "action": "ask", "pattern": "*" },
        { "permission": "edit", "action": "allow", "pattern": "src/**/*.ts" }
      ]
    }
  }
}
```

### 2.3 AI 提供商配置

**Anthropic**:

```bash
export ANTHROPIC_API_KEY=sk-ant-xxx
```

**OpenAI**:

```bash
export OPENAI_API_KEY=sk-xxx
```

**Google**:

```bash
export GOOGLE_API_KEY=xxx
```

**GitHub Copilot**:

```bash
# 通过 OAuth 认证，无需 API Key
opencode auth github-copilot
```

## 三、基本使用

### 3.1 启动服务

```bash
# 基础启动（监听 127.0.0.1:4096）
bun run dev

# 监听所有网络接口
bun run dev --hostname 0.0.0.0

# 指定端口
bun run dev --port 8080

# 启用 mDNS 发现
bun run dev --mdns
```

### 3.2 访问 Web 界面

启动后，访问：

- **本地**: http://localhost:4096
- **网络**: http://your-ip:4096

如果设置了密码，使用认证：

- 用户名：`opencode` (默认)
- 密码：`OPENCODE_SERVER_PASSWORD` 的值

### 3.3 创建会话

**Web 界面**:

1. 打开 Web 界面
2. 点击 "New Session"
3. 输入你的请求

**API 方式**:

```bash
curl -X POST http://localhost:4096/session \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My Session",
    "agent": "build"
  }'
```

### 3.4 发送消息

**Web 界面**:

1. 在输入框输入消息
2. 选择 Agent（build 或 plan）
3. 选择模型
4. 发送

**API 方式**:

```bash
curl -X POST http://localhost:4096/session/session_xxx/message \
  -H "Content-Type: application/json" \
  -d '{
    "parts": [
      { "type": "text", "text": "帮我创建一个排序函数" }
    ],
    "model": {
      "providerID": "anthropic",
      "modelID": "claude-sonnet-4-20250514"
    }
  }'
```

### 3.5 权限管理

当 AI 请求执行敏感操作（如 bash 命令、文件编辑）时：

1. 系统会弹出权限请求
2. 选择：
   - **Once**: 仅允许本次
   - **Always**: 总是允许（添加到规则）
   - **Reject**: 拒绝

**查看待处理权限**:

```bash
curl http://localhost:4096/permission
```

**响应权限请求**:

```bash
curl -X POST http://localhost:4096/permission/perm_xxx/reply \
  -H "Content-Type: application/json" \
  -d '{ "reply": "once" }'
```

## 四、常用命令

### 4.1 会话管理

```bash
# 创建会话
curl -X POST http://localhost:4096/session \
  -H "Content-Type: application/json" \
  -d '{ "title": "My Session" }'

# 获取会话列表
curl http://localhost:4096/session

# 获取会话详情
curl http://localhost:4096/session/session_xxx

# 删除会话
curl -X DELETE http://localhost:4096/session/session_xxx

# 分叉会话
curl -X POST http://localhost:4096/session/session_xxx/fork \
  -H "Content-Type: application/json" \
  -d '{ "messageID": "message_xxx" }'

# 中止会话
curl -X POST http://localhost:4096/session/session_xxx/abort
```

### 4.2 消息管理

```bash
# 获取消息列表
curl http://localhost:4096/session/session_xxx/message

# 获取单条消息
curl http://localhost:4096/session/session_xxx/message/message_xxx

# 回滚消息
curl -X POST http://localhost:4096/session/session_xxx/revert \
  -H "Content-Type: application/json" \
  -d '{ "messageID": "message_xxx" }'
```

### 4.3 提供商管理

```bash
# 获取提供商列表
curl http://localhost:4096/provider

# 获取模型列表
curl http://localhost:4096/provider/anthropic/model

# 设置认证
curl -X PUT http://localhost:4096/auth/anthropic \
  -H "Content-Type: application/json" \
  -d '{ "apiKey": "sk-ant-xxx" }'

# 删除认证
curl -X DELETE http://localhost:4096/auth/anthropic
```

### 4.4 文件操作

```bash
# 读取文件
curl "http://localhost:4096/file?path=/path/to/file.txt"

# 写入文件
curl -X POST http://localhost:4096/file \
  -H "Content-Type: application/json" \
  -d '{
    "path": "/path/to/file.txt",
    "content": "file content"
  }'

# 删除文件
curl -X DELETE http://localhost:4096/file \
  -H "Content-Type: application/json" \
  -d '{ "path": "/path/to/file.txt" }'
```

## 五、常见问题

### 5.1 安装问题

**Q: Bun 安装失败**

```bash
# 手动安装 Bun
curl -fsSL https://bun.sh/install | bash

# 验证安装
bun --version
```

**Q: 依赖安装失败**

```bash
# 清理并重新安装
rm -rf node_modules bun.lockb
bun install
```

### 5.2 启动问题

**Q: 端口被占用**

```bash
# 使用其他端口
bun run dev --port 8080

# 或查找占用端口的进程
lsof -i :4096
```

**Q: 无法访问 Web 界面**

- 检查防火墙设置
- 确保使用 `--hostname 0.0.0.0`
- 检查服务器日志

### 5.3 AI 提供商问题

**Q: ProviderAuthError**

- 检查 API Key 是否正确
- 确认环境变量已设置
- 验证网络连接

**Q: 模型不可用**

```bash
# 查看可用模型
curl http://localhost:4096/provider/anthropic/model
```

### 5.4 权限问题

**Q: 权限请求不弹出**

- 检查 SSE 连接是否正常
- 刷新 Web 界面
- 查看浏览器控制台错误

**Q: 如何修改权限规则**

```json
// 在 config.json 中配置
{
  "agent": {
    "build": {
      "permission": [{ "permission": "bash", "action": "allow", "pattern": "npm *" }]
    }
  }
}
```

### 5.5 性能问题

**Q: 响应缓慢**

- 检查网络连接
- 使用更快的模型
- 减少上下文长度（使用会话压缩）

**Q: 内存占用高**

- 归档旧会话
- 减少同时运行的会话数
- 重启服务
