### 文档结构原则

1. **单一职责**: 每个文档文件只关注一个主题
2. **避免重复**: 核心概念只在一个地方定义，其他地方引用
3. **代码位置**: 所有代码示例都标注实际文件路径和行号
4. **及时更新**: API 变更后必须同步更新文档

### 快速查找

- **查找代码**: 使用 `grep -r "函数名" packages/opencode/src`
- **查找类型**: 查看 `packages/sdk/js/src/gen/types.gen.ts`
- **查找路由**: 查看 `packages/opencode/src/server/routes/`
- **查找事件**: 查看 `packages/opencode/src/bus/bus-event.ts`
