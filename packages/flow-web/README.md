# Flow Web

LangGraph visual workflow editor for OpenCode.

## Quick Start

```bash
# Install dependencies
bun install

# Development
bun run dev

# Build
bun run build
```

## Configuration

Create `.env` file:

```bash
VITE_FLOW_API_URL=http://localhost:4097
```

## Features

- Visual workflow editor using React Flow
- Drag and drop nodes
- Real-time execution status
- Graph configuration management
